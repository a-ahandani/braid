Features

Your agent on git

Claude Code, Codex, Gemini CLI or opencode, with their own sign-in. It drafts commit messages and branch names, and resolves conflicts for you to review.

Code changes

Editor-grade diffs. Stage, unstage or discard one block, and edit in place.

Multiple repos, full control

Open a folder of repositories. Pull or fetch them all, merge pull requests, jump with ⌘⇧A.

Yours, start to finish

Your git, unchanged

Runs the git you already use. SSH keys, hooks and LFS just work.

No account

No sign-up, no login, nothing to pay for.

All local

Runs on your machine. No Ramulus server, no telemetry.

$ npx ramulus
