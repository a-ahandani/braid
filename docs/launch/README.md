## Copy

**Name:** Ramulus

**Tagline:** Every branch, in one graph. A local Git GUI.

**Description:** A Git GUI on the git you already have. Run `npx ramulus` in any repository and it opens in your browser. Editor diffs, staging by block, and the AI coding agent you already use. No account, no cloud. MIT.

**Links:** https://a-ahandani.github.io/ramulus/ and https://github.com/a-ahandani/ramulus

**First comment:**

I wanted a Git GUI that uses my own git, keys and hooks, and needs no account. Ramulus is one command, `npx ramulus`, and it runs on 127.0.0.1. It can also hand a merge conflict to Claude Code, Codex, Gemini CLI or opencode, with their own sign-in. Feedback and issues are welcome on GitHub.
